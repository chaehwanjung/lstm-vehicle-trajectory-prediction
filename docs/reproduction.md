# 실행 안내

분석은 Google Colab의 Tesla T4와 TensorFlow 2.21.0 환경에서 수행했다. 공개 노트북은 코드와 선별한 저장 그림을 포함한다. 업로드 과정에서 모델을 다시 학습하지 않았다.

1. Colab에서 `notebooks/01_lstm_trajectory_analysis.ipynb`를 연다.
2. 수업 제공 원본 파일을 Google Drive에 준비한다. 원본 데이터는 저장소에 없다.
3. 파일 경로 셀의 `data_path`와 `SAVED_BATCH_DIR`를 본인 환경에 맞춘다.
4. 저장 결과를 재사용하려면 원래 실험 폴더의 모델, scaler, manifest, 분할 인덱스와 평가표가 함께 필요하다.
5. 기본 `RUN_TRAINING=False`는 기존 결과를 재사용한다. 해당 아티팩트가 없으면 경로 확인 오류가 발생한다. 새 실험은 별도 폴더에서 `RUN_TRAINING=True`로 실행한다.

전체 학습에는 8개 모델 학습 시간이 필요하다. requirements는 노트북의 주요 패키지를 기록한 것이며 TensorFlow 외 버전은 고정하지 않았다. Colab에서는 Google Drive 연결 셀을 사용하며 일반 Jupyter에서는 그 셀을 건너뛰고 로컬 경로를 지정해야 한다.

원본 `raw_data`는 보존하고 모델 입력만 별도 배열로 만든다. 주변 차량 부재의 0 채움값은 실재 위치가 아니다. 원본 좌표 단위를 완전히 검증한 상태가 아니므로 결과는 정규화/원래 좌표 스케일을 구분해 읽는다.

저장 표는 과거 실행 결과다. 현재 노트북의 결과 경로가 같은 실험의 모델·scaler·분할을 가리키는지 확인한 뒤 재평가한다. 정리 과정에서는 코드 구문과 저장 결과·보고서의 수치 대응을 점검했다.
