# 자료 구성

- `PBL1_analysis.ipynb`: 모델·평가 코드를 보존하고 반복된 설명, 실행 번호, 세션 출력과 일부 행 단위 예제를 정리했다.
- 학습곡선·7대 궤적·시간별 오차·차로 상태별 오차·일정속도 비교: 노트북에 저장된 PNG에서 추출했다. 새 학습 결과가 아니다.
- `midterm_analysis_report.pdf`: 별도로 작성한 19쪽 분석 보고서다. 파일명에는 최종 완료로 오해할 표현을 사용하지 않았다.
- `model_comparison.csv`: 저장 평가표의 8개 정규화 지표를 옮겼다. 재학습해 산출한 표가 아니다.
- 발표 PPT·슬라이드 PDF, 이전 노트북 백업, 자기소개 문서, 원본 데이터와 학습 모델은 제외했다.

본인이 기획·전처리·실험·평가·보고서 작성을 수행했다. 팀 구성원은 정채환, 전재현, 진하영, 최형빈이다. 개인 역할은 작성자 확인을 반영했다.
